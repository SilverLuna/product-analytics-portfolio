# Product_Analytics

Привет меня зовут Настя, продуктовый аналитик с опытом работы с маркетинговыми данными и пользовательскими сценариями. В 2026 году завершила обучение по программе «Продуктовый аналитик» в Яндекс Практикуме, где получила системную практику в SQL, Python, продуктовых метриках, A/B-тестировании, когортном анализе, юнит-экономике и поиске точек роста продукта.
Есть UX-бэкграунд. Понимаю пользовательский путь, умею работать с CJM, User Flow и пользовательскими исследованиями, поэтому рассматриваю продукт не только через метрики, но и через поведение пользователей.

## Скилы
* SQL: PostgreSQL, SELECT, JOIN, GROUP BY, CTE, подзапросы, оконные функции, агрегации, фильтрация и преобразование данных, ad hoc-задачи.
* Python: Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook, предобработка и исследовательский анализ данных, визуализация.
* Аналитика: продуктовые метрики, воронки, конверсия, когортный анализ, User Journey, сегментация пользователей, поиск инсайтов и точек роста, A/B-тестирование, формулирование и проверка гипотез, выбор метрик, статистическая проверка результатов.
* BI и визуализация: Google Sheets, DataLens, Figma, Adobe.
* Дополнительно: анализ маркетинговых данных, оценка эффективности рекламных кампаний, анализ продаж и регионов, UX/UI, CJM, User Flow.
