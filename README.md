# Портфолио продуктового аналитика

Продуктовый аналитик с опытом анализа маркетинговых данных и пользовательских сценариев. Владею SQL (PostgreSQL) и Python (pandas, NumPy), работаю с продуктовыми метриками, воронками, когортным анализом и A/B-тестированием. Умею формулировать и проверять гипотезы, интерпретировать статистические результаты и находить точки роста продукта.

## Навыки
* SQL: PostgreSQL, JOIN, CTE, подзапросы, оконные функции, агрегации.
* Python: pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook.
* Продуктовая аналитика: воронки, конверсия, когортный анализ, сегментация, A/B-тесты, статистические гипотезы.
* BI и отчётность: DataLens, Google Sheets.
* Дополнительная экспертиза: UX/UI, CJM, User Flow, Figma, Adobe.

## Проекты по продуктовой аналитике
В репозитории собраны учебные проекты по продуктовой и маркетинговой аналитике, выполненные в ходе обучения и самостоятельной практики.


### [Исследование маркетплейса и A/B-тест бонуса на первую покупку](https://github.com/SilverLuna/product-analytics-portfolio/tree/main/01%20-%20Marketplace%20data%20exploration)

**Задача:** проанализировать продуктовые и маркетинговые метрики маркетплейса, найти точки роста и проверить влияние бонуса на первую покупку новых пользователей TikTok.

**Методы:** анализ воронки, конверсии и монетизации; A/B-тестирование; статистическая проверка гипотез; bootstrap-анализ распределения сумм заказов.

**Результаты:** конверсия в первую покупку за 21 день выросла с 0,93% до 7,51% (+6,58 п.п.; p-value = 1,72 × 10⁻¹⁹). ARPU вырос с 11,66 до 131,25.

**Бизнес-вывод:** бонус увеличивает конверсию и выручку на пользователя. Перед масштабированием необходимо оценить экономику бонуса с учётом его стоимости.

**Стек:** Python, pandas, NumPy, SciPy, Matplotlib.
