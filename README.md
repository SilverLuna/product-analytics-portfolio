# Product_Analytics

Продуктовый аналитик с опытом анализа маркетинговых данных и пользовательских сценариев. Владею SQL (PostgreSQL) и Python (pandas, NumPy), работаю с продуктовыми метриками, воронками, когортным анализом и A/B-тестированием. Умею формулировать и проверять гипотезы, интерпретировать статистические результаты и находить точки роста продукта.

## Навыки
* SQL: PostgreSQL, JOIN, CTE, подзапросы, оконные функции, агрегации, фильтрация и преобразование данных, ad hoc-задачи.
* Python: Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook, предобработка и исследовательский анализ данных, визуализация.
* Аналитика: продуктовые метрики, воронки, конверсия, когортный анализ, User Journey, сегментация пользователей, поиск инсайтов и точек роста, A/B-тестирование, формулирование и проверка гипотез, выбор метрик, статистическая проверка результатов.
* BI и визуализация: Google Sheets, DataLens, Figma, Adobe.
* Дополнительно: анализ маркетинговых данных, оценка эффективности рекламных кампаний, анализ продаж и регионов, UX/UI, CJM, User Flow.

A/B-тест: бонус на первую покупку в TikTok

Проверила гипотезу о влиянии бонуса на конверсию новых пользователей в первую покупку. Рассчитала конверсию за 21 день после регистрации, проверила статистическую значимость различий, проанализировала ARPU, ARPPU и AOV, а также исследовала распределение сумм заказов с помощью bootstrap.

Результат: конверсия выросла с 0,93% до 7,51% (+6,58 п.п.; p-value = 1,72 × 10⁻¹⁹). ARPU вырос с 11,66 до 131,25. Сформулировала рекомендации по дальнейшей проверке экономики бонуса.

Стек: Python, pandas, NumPy, SciPy, статистические тесты, bootstrap.
