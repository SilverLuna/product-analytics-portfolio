# Поиск инсайтов и точек роста сервиса доставки еды «Всё.из.кафе»


Для работы предоставлены данные сервиса доставки еды «Всё.из.кафе». Руководство ждёт от продукта роста. Необходимо найти инсайты, которые позволят сервису повысить показатель удержания пользователей и улучшить взаимодействие с партнёрами. Ближе познакомиться с работой сервиса, выявить узкие места и предложить решения для удержания пользователей и повышения эффективности сотрудничества с ресторанами.


## Задачи:

1. Изучить пользовательский путь и проанализировать конверсии через воронки.
2. Сегментировать пользователей с помощью RFM-модели для оценки лояльности и поведения клиентов.
3. Кластеризировать рестораны методом K-Means, чтобы выделить группы с разными моделями работы и разработать персонализированные маркетинговые стратегии.


## Результаты исследования:

1. После предобработки осталось 93,8% исходных данных. Предоставленная информация качественная, нет дубликатов, пропуски только в уместных местах, значения почти адекватные. Есть проблемы с событием подтверждения номера телефона, эти записи убрали.
2. После изучения пользовательского пути и воронки видна относительно сильная просадка на этапе подтверждения телефона. Похоже новый алгоритм подтверждения мобильного телефона и адреса доставки, внедрённый командой разработки, имел негативный эффект. У мобильной версии приложения явные проблемы с этапом регистрации. Конверсия с главной страницы на регистрацию высокая, а потом проседает и в десктопной версии на 10%, и в мобильной больше, чем на 20%.
3. Для запуска нескольких рекламных кампаний, направленных на удержание платящих пользователей и их возврат в сервис, сегментировали пользователей на различные поведенческие сегменты с помощью RFM-сегментации по трём показателям: давность (Recency), частота покупок (Frequency), сумма трат (Monetary). Выделили RFM-сегменты и изучим распределение пользователей по ним.
4. Чтобы лучше понимать поведение ресторанов и предлагать им персонализированные условия сотрудничества, а также создавать персонализированные предложения для пользователей, провели кластеризацию ресторанов по следующим параметрам: общее количество заказов,
средняя стоимость заказа, общее число заказанных уникальных блюд (ассортимент ресторана). Оптимально методом .inertia_ выделили 3 кластера.

## Использование результатов исследования:

Анализ воронки показал проблемы на этапе подтверждения телефона у мобильной версии сервиса доставки, разработчики указывали на изменения в системе. Просадка воронки есть и у десктопной версии на этапе регистрации. После этих шагов большинство клиентов остаются для заказа, значит из-за этого узкого места воронки сильно теряется доход. Проблема скорее всего техническая (судя по графику времени между шагами) или в интерфейсе приложения.
RFM сегментация определила, что людей, совершивших 1 заказ, подавляющее количество. Они готовы тратить деньги, но возвращается за вторым заказом только четверть, за 3+ еденицы. Стоит проверить источники привлечения, их эффективность и окупаемость. Те, кто сделал единичный заказ и забросил сервис могли быть не целевой аудиторией. Провести маркетинговые акции для тех, кто совершил 2+ заказа, для создания платящего ядра лояльных пользователей.
Кластеризация ресторанов показала, что есть 2 основных заведения. Они составляют основной объём по заказам, предлагают обширное меню по умеренным ценам. Остальные 19 заведений отработали меньше 200 заказов, ценны в них сильно варьируются при более скромном меню. Если добавить больше крупных заведений в сервис, можно увеличить постоянную базу клиентов и частоту заказов, нужно больше ресторанов, как во стором кластере. Остальным двум надо обновить систему привлечения и стимуляции повторных заказов.
