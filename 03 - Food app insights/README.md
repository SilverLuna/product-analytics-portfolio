# Поиск инсайтов и точек роста сервиса доставки еды «Всё.из.кафе»

> Учебный проект по анализу пользовательской воронки, повторных заказов и сегментации ресторанов.

## Контекст и цель

Сервис доставки еды хочет повысить удержание пользователей и улучшить взаимодействие с ресторанными партнёрами. Для этого важно найти проблемные этапы пользовательского пути, изучить частоту повторных заказов и выделить группы ресторанов с различными показателями работы.

**Цель:** выявить точки потери пользователей и подготовить рекомендации по удержанию и развитию партнёрской сети.

## Что было сделано

- Выполнена предобработка данных и проверены пропуски, дубликаты и аномальные события.
- Построена воронка пользовательского пути и изучены различия между мобильной и десктопной версиями.
- Проведена RFM-сегментация по давности, частоте и сумме покупок.
- Рестораны кластеризованы методом K-Means по числу заказов, средней стоимости заказа и ассортименту.

## Ключевые результаты

- После предобработки осталось **93,8%** исходных данных.
- В воронке регистрации обнаружена просадка на этапе подтверждения телефона; она была заметнее в мобильной версии. В исходном анализе отмечено снижение конверсии примерно на 10% в десктопной версии и более чем на 20% в мобильной.
- RFM-анализ показал, что значительная часть пользователей совершила только один заказ; до второго заказа возвращалась примерно четверть пользователей.
- Для анализа ресторанов выделено **3 кластера**. Два ресторана формировали основной объём заказов; остальные 19 ресторанов имели менее 200 заказов каждый.

## Выводы и рекомендации

Стоит проверить путь подтверждения телефона, особенно в мобильной версии, и отдельно измерить конверсию на каждом шаге регистрации. Поскольку обнаруженная просадка сама по себе не доказывает техническую причину, полезно дополнить анализ проверкой ошибок и UX-тестированием.

Для роста повторных заказов можно проверить реактивационные коммуникации для пользователей с одним заказом и разработать предложения для сегментов с высокой частотой и суммой покупок. С ресторанами стоит работать с учётом их кластеров: отдельно исследовать практики лидеров по заказам и причины низких объёмов у остальных партнёров.

## Инструменты

Python, pandas, NumPy, SciPy, Matplotlib, Seaborn, scikit-learn (K-Means).
