# A/B-тест алгоритма рекомендаций в развлекательном приложении

> Учебный проект по дизайну эксперимента, проверке корректности разбиения и анализу ключевой метрики.

## Контекст и цель

В развлекательном приложении с бесконечной лентой внедрён новый алгоритм рекомендаций. Команда предполагает, что более релевантный контент повысит долю успешных первых сессий — сессий, в которых пользователь просмотрел не менее четырёх страниц.

**Цель:** оценить параметры A/B-теста, проверить качество разбиения пользователей и определить, есть ли статистически значимое изменение ключевой метрики.

## Что было сделано

- Рассчитан плановый размер выборки и ожидаемая длительность эксперимента.
- Проверены пересечения пользователей и распределение групп по размеру.
- Сравнены группы по типу устройства и региону.
- Проверена разница в доле успешных первых сессий.

## Ключевые результаты

- При заданных параметрах плановый размер выборки составил **82 080 пользователей** — по **41 040** на группу; при трафике около **9 907 пользователей в день** расчётная длительность теста — примерно **9 дней**.
- Пересечений пользователей между группами не обнаружено, разница в размерах групп составляла менее 1%.
- Обнаружены небольшие различия по устройствам (около 2%) и более заметные различия по регионам MENA и CIS (до 6%), которые следует учитывать при интерпретации.
- Статистически значимого изменения доли успешных первых сессий не обнаружено (`p-value ≈ 0,578`). В исходном отчёте округлённые значения составляли около **32%** в контроле и **31%** в тесте.

## Выводы и рекомендации

Тест не подтвердил улучшения ключевой метрики после внедрения нового алгоритма. Не следует рекомендовать полный запуск только на основании этого эксперимента. Перед окончательным решением необходимо убедиться, что фактическая выборка достигла планового размера, сверить точные значения метрики и проверить возможное влияние регионального дисбаланса.

## Дизайн эксперимента

- **Ключевая метрика:** доля успешных первых сессий (`good_session`).
- **Плановый размер выборки:** 82 080 пользователей, по 41 040 на группу.
- **MDE:** 3% (смысл заданного изменения следует трактовать в соответствии с расчётом в ноутбуке).
- **Уровень значимости:** α = 0,05.
